# Deutsch AI Tutor

مدرّسة ألمانية بالذكاء الاصطناعي (كلارا) من المستوى A1 إلى A2 (32 درسًا)، بمحادثة صوتية. تتحدث الألمانية بصوت مسموع، تعرض الجملة وترجمتها العربية، وتصحح أخطاءك وتشرح بالعربي.

## ماذا يعمل وماذا لا يعمل

| الميزة | الحل المستخدم | التكلفة |
|---|---|---|
| سماع صوتك | التعرف على الصوت داخل المتصفح (Web Speech API) | مجاني |
| نطق المعلمة بالألمانية | نطق المتصفح (speechSynthesis) | مجاني |
| ذكاء المعلمة وتصحيحها | واجهة Claude من Anthropic عبر خادمك | **مدفوع حسب الاستخدام** |
| بدون مفتاح API | وضع تجريبي بردود مكتوبة مسبقًا | مجاني |

- لم أستخدم WebRTC لأن حل المتصفح مجاني ويعمل على الموبايل. خدمات الصوت الفوري عبر WebRTC (مثل Realtime API) مدفوعة، ويمكن إضافتها لاحقًا.
- المفتاح يبقى على الخادم فقط في متغير بيئة، ولا يظهر في كود الواجهة.
- في الخادم حد طلبات لكل زائر (افتراضيًا 40 طلبًا كل 15 دقيقة) لحماية رصيدك. يمكن تغييره بـ `RATE_LIMIT`.
- تقدمك (الدرس والمحادثة) يُحفظ في متصفحك فقط، بلا قاعدة بيانات.
- تصحيح النطق تقريبي: يعتمد على ما فهمه المتصفح من صوتك، وليس تحليلًا صوتيًا حقيقيًا.

## المتصفحات المدعومة للصوت

- iPhone: Safari (iOS 14.5 أو أحدث).
- Android: Chrome.
- متصفحات لا تدعم التعرف على الصوت (مثل Firefox): يظهر مربع كتابة تلقائيًا.
- يحتاج الميكروفون إلى رابط HTTPS، وReplit يوفره.

## التشغيل على Replit من الموبايل، خطوة بخطوة

قد تختلف أسماء الأزرار قليلًا حسب إصدار التطبيق.

1. افتح موقع **replit.com** (أو تطبيق Replit) وسجّل الدخول.
2. أنشئ مشروعًا جديدًا (**Create Repl**) بقالب **Node.js** وسمّه `deutsch-ai-tutor`.
3. ارفع ملف `deutsch-ai-tutor.zip` إلى المشروع من قائمة الملفات (زر الثلاث نقاط ثم **Upload file**).
4. افتح **Shell** من داخل المشروع ونفّذ:
   ```
   unzip -o deutsch-ai-tutor.zip
   cp -r deutsch-ai-tutor/. .
   rm -rf deutsch-ai-tutor deutsch-ai-tutor.zip
   npm install
   ```
   إذا ظهر الملف `package.json` الأصلي للقالب فاستبدله بالملف من المشروع (الأمر `cp` أعلاه يفعل ذلك).
5. جرّب الوضع التجريبي أولًا: اضغط **Run**. ينفّذ الأمر `npm run build && npm start`. افتح نافذة المعاينة (Webview) أو الرابط الذي يظهر.
6. لتفعيل الذكاء الاصطناعي:
   - أنشئ مفتاحًا من console.anthropic.com وأضف رصيدًا بسيطًا في الفوترة.
   - في Replit افتح **Tools ثم Secrets** (أيقونة القفل) وأضف سرًّا باسم `ANTHROPIC_API_KEY` وقيمته مفتاحك.
   - اضغط **Stop** ثم **Run** من جديد. يختفي شريط «وضع تجريبي».
7. افتح الرابط في Safari أو Chrome على هاتفك، واسمح للميكروفون عند الطلب، ثم اضغط الدائرة الزرقاء وتحدث.

للنشر الدائم: من Replit اختر **Deploy** (قد يكون للنشر الدائم تكلفة من Replit نفسه).

## التشغيل على الكمبيوتر

```
npm install
cp .env.example .env     # ضع مفتاحك داخل .env أو اتركه فارغًا للوضع التجريبي
npm run build && npm start   # ثم افتح http://localhost:3000
```

للتطوير: `npm run dev` ثم افتح http://localhost:5173

## البنية

```
server/index.ts       الخادم: /api/chat و /api/status وحد الطلبات ومعالجة الأخطاء
server/curriculum.ts  المنهج: 16 درسًا A1 ثم 16 درسًا A2
server/prompt.ts      تعليمات المعلمة للذكاء الاصطناعي
server/demo.ts        الردود التجريبية
src/App.tsx           شاشة التطبيق ومنطق المحادثة
src/lib/speech.ts     الاستماع والنطق
src/components/       الشخصية وأزرار التحكم
```

## كيف تتقدم الدروس

تقرر المعلمة بنفسها متى حققت أنت هدف الدرس (عادة بعد 3 إلى 5 ردود)، فيتقدم الشريط إلى الدرس التالي. الشريط يعرض تقدمك داخل المستوى الحالي (A1 ثم A2)، وتتغير الشارة تلقائيًا عند الانتقال إلى A2. لتغيير النموذج استخدم `ANTHROPIC_MODEL`.

### دروس A2

روتين اليوم، الهوايات، الطقس، الملابس، المقادير في السوبرماركت، الأفعال المساعدة (يمكن/يجب/يريد)، المواعيد والدعوات، عند الطبيب، الماضي (Perfekt مع haben ومع sein)، البيت، المواصلات، الهاتف والرسائل، العمل والتقديم لوظيفة، الخطط والأسباب (weil)، ثم مراجعة. لإضافة دروس أخرى أضفها في **نهاية** القائمة في `server/curriculum.ts` فقط، حتى لا يختل تقدم المستخدمين المحفوظ.
